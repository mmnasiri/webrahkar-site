# وب‌راهکار بهینه — نسخهٔ اول وب‌سایت

وب‌سایت فارسی، راست‌به‌چپ، واکنش‌گرا و بدون وابستگی به کتابخانه‌های بیرونی. طراحی طوری انجام شده که صفحهٔ معرفی کسب‌وکار اصلی باشد و دموهای تعاملی فقط یکی از بخش‌های آن باشند.

## فایل‌ها

- `index.html`: ساختار و محتوای صفحه
- `styles.css`: طراحی، رنگ‌ها، واکنش‌گرایی و اجزای رابط
- `app.js`: منوی موبایل، سال جاری، پیوندهای دمو و رفتار فرم تماس
- `site-config.js`: تنظیمات متمرکز ایمیل، تلفن و نشانی دموها
- `favicon.svg`: نشان سادهٔ وب‌سایت

## قبل از انتشار عمومی

1. در `site-config.js`، مقدار `contactEmail` را با ایمیل واقعی جایگزین کنید.
2. در مرورگر، فرم تماس را آزمایش کنید. نسخهٔ فعلی از `mailto:` استفاده می‌کند و اطلاعات را در سرور ذخیره نمی‌کند.
3. متن و حوزه‌های خدمات را بررسی کنید تا با خدماتی که واقعاً آمادهٔ ارائه‌شان هستید تطبیق داشته باشند.
4. دموها در حال حاضر نمونهٔ مفهومی‌اند. پس از استقرار یک دمو، URL آن را در `demoLinks.scheduling` قرار دهید؛ پیوند دمو به صورت خودکار فعال می‌شود.
5. هیچ گذرواژه، توکن، دادهٔ مشتری یا کلید API را در مخزن عمومی قرار ندهید.

## انتشار با GitHub Pages

1. در GitHub یک مخزن عمومی با نامی مانند `webrahkar-site` بسازید.
2. تمام فایل‌های این پوشه را در ریشهٔ مخزن قرار دهید و commit کنید.
3. در Settings مخزن، به Pages بروید.
4. گزینهٔ ساخت از branch اصلی (`main`, root) را انتخاب کنید و ذخیره کنید.
5. پس از انتشار، نشانی نمایش‌داده‌شده در GitHub Pages را باز کنید و دسکتاپ و موبایل، پیوندها و فرم را آزمایش کنید.

## اتصال دموها در آینده

وب‌سایت اصلی می‌تواند روی GitHub Pages باقی بماند. هر دمو که به Python/Django نیاز دارد، جداگانه روی یک سرویس سازگار مستقر می‌شود و URL آن از طریق `site-config.js` به این وب‌سایت پیوند می‌خورد. در آینده می‌توان دامنهٔ اختصاصی و زیردامنه‌ای مانند `demo.example.com` در نظر گرفت؛ انتخاب دامنه هنوز انجام نشده است.

## تصمیم‌های طراحی

- نام «وب‌راهکار بهینه» فعلاً عنوان کاری وب‌سایت است و به‌عنوان نام نهایی حقوقی شرکت یا نام محصول معرفی نشده است.
- شعار محوری: «از مسئله شروع می‌کنیم، نه از فناوری.»
- از آمار، مشتریان، نتایج یا گواهی‌های تأییدنشده استفاده نشده است.
- محتوای دموها صریحاً شماتیک/در حال طراحی معرفی می‌شود تا با محصول مستقرشده اشتباه نشود.
- هیچ فونت، تصویر، کتابخانه یا سرویس خارجی برای رندر پایهٔ صفحه لازم نیست؛ نمایش از فونت‌های نصب‌شدهٔ دستگاه استفاده می‌کند.
