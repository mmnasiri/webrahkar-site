# تهران‌راهکار — وب‌سایت اصلی

وب‌سایت معرفی فارسی و راست‌به‌چپ برای معرفی خدمات سازمانی، ابزارهای برنامه‌ریزی و تصمیم‌یار، سامانه‌های تحت وب، نمونه‌های تعاملی و راه ارتباط با مخاطبان. سایت با HTML، CSS و JavaScript ساخته شده و برای میزبانی ایستا طراحی شده است.

## فایل‌ها
- `index.html`: ساختار و محتوای صفحه
- `styles.css`: طراحی، اجزای رابط و واکنش‌گرایی
- `app.js`: منوی موبایل، پیوندهای دمو و ارسال فرم تماس
- `site-config.js`: تنظیمات نام سایت، ایمیل، کلید فرم Web3Forms و پیوند دموها
- `favicon.svg`: نشان سایت
- `robots.txt` و `sitemap.xml`: راهنمای خزنده‌های موتور جست‌وجو و نقشهٔ سایت

## فرم تماس
فرم به Web3Forms متصل است و پیام را از داخل صفحه ارسال می‌کند؛ بازدیدکننده به Outlook یا برنامهٔ ایمیل نیاز ندارد. کلید Web3Forms برای استفاده در کد مرورگر طراحی شده است و رمز حساب ایمیل نیست. هیچ گذرواژه، توکن خصوصی، کلید API محرمانه، اطلاعات مشتری یا دادهٔ حساس را در مخزن عمومی قرار ندهید.

## انتشار و ویرایش
- مخزن: https://github.com/mmnasiri/webrahkar-site
- دامنهٔ اصلی: https://tehranrahkar.com/
- مخزن عمومی است؛ تمام HTML، CSS، JavaScript و تنظیمات سمت مرورگر برای عموم قابل مشاهده‌اند.
- تغییرات در شاخهٔ `main` با سازوکار انتشار فعلی سایت منتشر می‌شوند.

## دموها
دموی برنامه‌ریزی ارسال سفارش‌ها در مسیر `delivery-demo/` با حل‌گر دقیق مبتنی بر شمارش مسیرهای مجاز و برنامه‌ریزی پویای تخصیص اجرا می‌شود؛ هر تغییر در ورودی‌ها دوباره محاسبه می‌شود و جواب از پیش ذخیره نشده است. نقشه و زمان‌های آن آموزشی و شماتیک‌اند و ادعایی دربارهٔ نقشه یا ترافیک زنده ندارند. دموهای دیگر تا زمان اتصال به موتور اجرایی واقعی با برچسب مفهومی/در حال توسعه نمایش داده می‌شوند.

## هویت و پیام محوری
- نام فعلی برند سایت: «تهران‌راهکار».
- دامنهٔ `webrahkar.ir` برای تغییرمسیر و دریافت ایمیل‌های قبلی حفظ می‌شود.
- لوگوتایپ برداری فعلی در `assets/images/tehranrahkar-wordmark.svg` نگهداری می‌شود و در سربرگ و پابرگ سایت استفاده شده است؛ بازنگری‌های آتی هویت بصری در همین مسیر ثبت می‌شوند.
- شعار سایت: «راهکارهای کاربردی، متناسب با نیاز واقعی شما.»
- تمرکز بر طراحی ابزارهای کاربردی برای برنامه‌ریزی، تصمیم‌گیری، گردش‌کارها و سامانه‌های سازمانی.
